# 📊 chart-dashboard

**A standalone Chart.js dashboard that turns CSV files into interactive
charts — bar, line, pie, scatter, area.**

Upload a CSV (drag & drop), preview the data in a table, pick a chart type,
and hit **Generate Chart**. A local Python renderer (standard library only —
zero dependencies) builds the Chart.js config and the page draws it.

## 🛠 Tech

- **HTML** + **Tailwind CSS** (CDN) — the UI
- **Chart.js** (CDN) — chart drawing
- **Python 3.10+** standard-library HTTP server — the local renderer
- Vanilla JavaScript — no build tools, no npm, no `pip install`

## ✨ Features

- 📂 CSV upload — drag & drop or browse (+ one-click **sample dataset**)
- 🧾 Table preview with sticky header (first 10 rows)
- 🎛 Pick the **X axis** + **Y axis** (numeric columns auto-detected)
- 📈 Bar / line / pie / scatter / area charts
- 🔌 Charts generated by the **local Python renderer** via `fetch()`
- 🛟 Status badge + clear hint if the renderer isn't running
- ⬇ Download any chart as PNG *(advanced dashboard)*

## 🚀 Install & run

Nothing to install — just Python.

```bash
cd chart-dashboard
python renderer.py
```

Then open **http://localhost:8787** in your browser → drop a CSV (or click
**Sample data**) → choose a chart type → **Generate Chart**.

> The page needs internet on first open (Tailwind + Chart.js load from a CDN).
> If the renderer isn't running, the **Generate Chart** button shows a hint
> with the start command.

## 🔌 Renderer API

| Endpoint | Purpose |
| --- | --- |
| `GET /api/health` | `{ "ok": true, "service": "chart-dashboard", "version": "2.0" }` |
| `POST /api/chart` | build a Chart.js config |
| `GET /` | serve the dashboard + static files |

`POST /api/chart`

```json
{
  "type": "bar",
  "xAxis": "Category",
  "yAxis": "Revenue",
  "rows": [{ "Category": "Electronics", "Revenue": "15200" }]
}
```

`type` may be `bar`, `line`, `pie`, `scatter` or `area`. The response is a
**Chart.js config** the page draws directly. For bar / line / pie / area,
duplicate X-axis values are automatically summed; `scatter` needs a
**numeric X column** (it uses raw `{x, y}` points).

## 🧪 Test the renderer


## 🗂 Project structure

```

├── index.html                # ✅ the simple all-in-one app (the UI)
├── renderer.py               # 🐍 local renderer (Python stdlib, :8787)
├── test-renderer.py          # integration test for the renderer
├── dashboard-advanced.html   # advanced dashboard (multi-series, PNG export)
├── app.js                    # advanced dashboard logic
├── csv.js                    # CSV parsing for the advanced dashboard

├── chart-config.js           # chart-building logic (Node renderer)
├── server.js                 # alternative Node renderer (same API / port)
├── test-api.js               # integration test for the Node renderer
├── sample.csv                # sample dataset
├── styles.css                # advanced dashboard styles
└── package.json              # npm scripts for the Node renderer
```
